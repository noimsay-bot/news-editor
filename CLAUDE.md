# CLAUDE.md — Claude Code instructions

Read and follow [AGENTS.md](./AGENTS.md), then read [DEVELOPMENT_SPEC.md](./DEVELOPMENT_SPEC.md) **in full**. Both are binding. The most important product rule is **strictly no generation of missing media content or speech**: no generative AI, diffusion/inpainting, hallucinated words, voice cloning, synthetic frames or synthetic image details. Only conservative transformations on actually recorded footage/audio, with expert controls and non-destructive source preservation.

Start by inspecting the repository and running the project/test discovery commands. Implement the earliest incomplete milestone with real code and tests, and update `docs/PROGRESS.md`, `docs/DECISIONS.md`, and `docs/TEST_REPORT.md`. Do not stop after producing a plan or a mock screen.
