# 설계 결정 기록 (DECISIONS)

## D-001 (2026-10-16) 엔진 언어: Node.js (Python/PySide6 대신)
- 명세 §5.1은 "기존 Shotcut/MLT 편집기가 있으면 유지하고 복구 엔진을 분리 통합, 빈 저장소면 Python/PySide6"라고 한다.
- 이 저장소에는 이미 Shotcut(MLT/FFmpeg)을 엔진으로 쓰는 Node.js 보조 앱(`app/`)이 있다. 이 PC에는 Python이 설치되어 있지 않고(Microsoft Store 바로가기만 있음), 회사 백신(AhnLab V3)이 새 컴파일러·런타임 실행을 막은 이력이 있다(인수인계서 참고).
- 그래서 **GUI와 분리된 `engine/` 패키지 + `cli/restoration-cli.mjs`를 Node.js(외부 의존성 0)로 구현**하고, FFmpeg/ffprobe는 설치된 Shotcut의 실행 파일을 인수 배열로 호출한다.
- 오디오 DSP(바이쿼드, FFT, STFT)는 엔진 안에 직접 구현해 동작을 문서화하고 시험한다. 외부 패키지가 없으므로 라이선스 의존이 없다.

## D-002 오디오 복구 알고리즘: 자체 STFT 스펙트럼 감쇠 (FFmpeg afftdn 대신)
- afftdn은 잡음 프로파일을 클립 처음부터 적용하기 어렵고 내부 파라미터 매핑을 명세대로 문서화하기 어렵다.
- 자체 구현 `nrs-spectral-attenuation-1` (`engine/audio.mjs`):
  - 순서: 하이패스(2단 24dB/oct) → 노치(50/60Hz+고조파) → 파라메트릭 EQ → STFT 감쇠(2048/512, sqrt-Hann) → 구간 바이패스 → wet/dry
  - **이득 g ∈ [gmin, 1]로 고정, 위상 유지** → 어떤 주파수 성분도 증폭하지 않아 입력에 없던 성분이 생기지 않는다(P0). 위반 시 SAFETY_VIOLATION으로 렌더 중단.
  - 강도 매핑: 최대 감쇠 = 0.30×strength dB, 과감산 α = 1 + strength/100, 음성 대역(300~3400Hz) 보호 = 음성 프레임에서 감쇠를 min(att, 12dB)×(1−protect)로 제한
  - 잡음 추정: 잡음 구간 지정 시 정적 프로파일, 미지정 시 1.5초 창 최소값 추적(비정적)
  - 강도 0 + 필터 없음(또는 wet 0)이면 처리 자체를 건너뛰어 샘플 동일(0% = 원음)

## D-003 DeepFilterNet: 기본 비활성(연구 후보)
- 명세 §11: "금지 원칙 적합성 검증 전 제품 기본 활성화 금지".
- 이전 세션에서 앱 기본값을 DFN 최대로 두었으나(사용자 요청), 명세서를 따르기로 한 사용자 지시에 따라 **기본 OFF + "연구용·검증 전" 표시 + 자동 사전 렌더 중지(`voicePrecompute: false`)**로 바꿨다. 기능 자체는 사용자가 켜면 쓸 수 있다.
- 엔진(`engine/`)은 DFN을 사용하지 않는다.

## D-004 기존 앱의 자동 보정 기본값
- 명세 §4 "사용자가 승인하지 않은 자동 보정을 완성본에 적용하지 않는다". 흔들림 컷·WB·HDR 역광·보이스 아이솔레이션 옵션을 **기본 해제**로 바꿨다(분석은 계속 하되 적용은 사용자가 켬).

## D-005 출력 프리셋
- 명세 §F-07: 송출 규격 미확정 → 고정 "JTBC 송출 프리셋" 금지. 기존 앱의 XDCAM HD422 50M 값은 사용자가 제공한 EDIUS 프리셋 파일에서 가져온 값이며 "송출 규격 미확정·인제스트 미검증"으로 표시를 바꿨다. 사용자 입력형 프리셋은 M4에서 구현.

## D-006 테스트 자료
- 명세 §7.1: 테스트는 합성·비민감 fixture만. `engine/fixtures.mjs`가 결정적 난수로 말소리 유사 신호·지속 잡음·60Hz 험·무음·29.97fps 영상을 만든다. 실제 취재 원본은 커밋하지 않고(`.gitignore`), 수동 확인 결과만 문서에 수치로 기록한다.

## D-007 렌더 안전
- 출력 = 원본 경로면 거부, 렌더 전후 원본 SHA-256 비교, 임시 파일(`.이름.partPID.확장자`) → ffprobe 검증 → 원자적 이동, 취소 시 부분 파일 삭제, 미구현 효과가 켜져 있으면 NOT_IMPLEMENTED로 실패(가짜 결과 금지).
- 부분 구간 영상 렌더는 프레임 정확도를 보장할 수 없어 M4(재인코딩)로 미룸.
